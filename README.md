## Description

This project implements a system to detect whether a text was written by a human or generated by artificial intelligence, analyzing **two linguistic signals** with pretrained language models:

| Signal | Definition | Human text | AI text |
|--------|------------|------------|---------|
| **Perplexity** | How surprising the text is to the model | Low (predictable) | Variable, often low |
| **Burstiness** | Variability of perplexity across sentences | High (natural variation) | Low (artificial consistency) |

Combining both signals significantly improves accuracy over a perplexity-only analysis.

## How it works

1. **Perplexity calculation** — A language model (`distilgpt2` by default) measures the mean token cross-entropy of the text: `perplexity = exp(loss)`.

2. **Burstiness calculation** — The text is split into sentences and each one is scored for perplexity. Burstiness is the coefficient of variation: `std_ppl / mean_ppl`.

3. **Classification** — Calibratable thresholds determine whether the text is *human*, *AI*, or *uncertain*:
   - **HUMAN**: low perplexity / high burstiness
   - **AI**: low perplexity and low burstiness (artificial consistency)
   - **UNCERTAIN**: values in the intermediate zone

4. **Optional calibration** — Automatic threshold tuning from labeled examples.

## Quick start

### As a Python module

```python
from detector_ia import AITextDetector

detector = AITextDetector()  # model: distilgpt2

text = "Artificial intelligence is transforming society in many ways."
result = detector.analyze(text)

print(f"Result:      {result.result.value}")   # human, ai, or uncertain
print(f"Confidence:  {result.confidence:.2%}")
print(f"Perplexity:  {result.perplexity:.2f}")
print(f"Explanation: {result.explanation}")
```

### With burstiness (dual approach)

```python
from detector_ia import BurstinessScorer, PerplexityScorer

scorer = PerplexityScorer()
burst = BurstinessScorer(scorer)

analysis = burst.score(text)
print(f"Burstiness: {analysis['burstiness']:.4f}")
print(f"Mean per-sentence perplexity: {analysis['mean_ppl']:.2f}")
```

## Main API

### `AITextDetector`

Main detector with three-way classification.

**Parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `model_name` | `str` | `"distilgpt2"` | Language model used for perplexity |
| `device` | `str \| None` | `None` | `"cuda"`, `"cpu"`, or auto-detect |
| `ai_threshold` | `float` | `50.0` | Perplexity threshold for AI |
| `human_threshold` | `float` | `10.0` | Lower threshold for human |
| `min_text_length` | `int` | `20` | Minimum length (characters) for analysis |
| `use_log_scale` | `bool` | `True` | Compare on a logarithmic scale |
| `scorer` | `PerplexityScorer \| None` | `None` | Inject a custom scorer (for testing) |

**Methods:**

```python
result = detector.analyze(text)                       # Analyze a single text
results = detector.batch_analyze([t1, t2, t3])        # Analyze multiple texts
stats = detector.get_statistics()                     # Analysis statistics
detector.set_thresholds(ai_threshold=60.0, human_threshold=15.0)
calibration = detector.calibrate(human_texts, ai_texts)  # Calibrate with examples
info = detector.get_model_info()                      # Model information
```

### `DetectionAnalysis`

Result of an analysis:

| Attribute | Description |
|-----------|-------------|
| `text` | Analyzed text |
| `perplexity` / `log_perplexity` | Perplexity scores |
| `result` | `DetectionResult` (`HUMAN`, `AI`, `UNCERTAIN`) |
| `confidence` | Confidence (0.0 – 1.0) |
| `is_too_short` / `is_empty` | Validity flags |
| `explanation` | Explanation of the result |

### `PerplexityScorer`

Low-level scorer:

```python
scorer = PerplexityScorer(model_name="distilgpt2", device="cpu")
ppl = scorer.score(text)
scores = scorer.batch_score(texts)
info = scorer.get_model_info()
```

### `BurstinessScorer`

```python
burst = BurstinessScorer(ppl_scorer)
```

### Evaluating against any dataset

Use this script to evaluate the detector against any dataset with `text`/`label` columns (JSON or CSV):

```python
"""Evaluate the AI detector against any JSON or CSV dataset."""
import argparse
import csv
import json

from detector_ia import AITextDetector


def load_json(path):
    with open(path, encoding="utf-8") as f:
        return json.load(f)


def load_csv(path):
    with open(path, newline="", encoding="utf-8") as f:
        return list(csv.DictReader(f))


def main():
    parser = argparse.ArgumentParser(description="Evaluate the AI detector on a dataset")
    parser.add_argument("--path", required=True, help="Path to the dataset file")
    parser.add_argument("--format", choices=["json", "csv"], default="json")
    parser.add_argument("--text-key", default="text")
    parser.add_argument("--label-key", default="label")
    parser.add_argument("--limit", type=int, default=None)
    args = parser.parse_args()

    dataset = load_json(args.path) if args.format == "json" else load_csv(args.path)
    if args.limit:
        dataset = dataset[: args.limit]

    detector = AITextDetector(device="cpu")
    correct = total = 0

    for item in dataset:
        text = item[args.text_key]
        label = item[args.label_key]
        actual = "human" if str(label).lower() in ("0", "human") else "ai"
        predicted = detector.analyze(text).result.value
        total += 1
        if predicted == actual:
            correct += 1

    print(f"Accuracy: {correct / total:.2%} ({correct}/{total})")


if __name__ == "__main__":
    main()
```

```bash
# JSON dataset
python evaluate_detector.py --path ./data/train.json --format json --limit 100

# CSV dataset
python evaluate_detector.py --path ./data/dataset.csv --format csv
```

## Limitations

- **Model dependence**: results depend on the model used to compute perplexity.
- **Short texts**: texts shorter than 20 characters cannot be analyzed accurately.
- **Domain**: works best with general text; highly specialized text may produce false positives.
- **False positives**: very uniform human text (forms, automated summaries) can be classified as AI.
